IFS Projects Plug-in

Hi, this is the home of the IFS Projects plug-in for IBM Rational Developer for i.

 Version: 1.0.0.b004

Introduction

IFS Projects is an open source plug-in for IBM Rational Developer for i. It opens SSH terminals from the Remote Systems view and supports IFS projects (iproj.json), which are built with gmake or TOBi (makei).

The IFS Projects Project Team


Tools/400, Thomas Raddatz

Features

  • SSH terminals for IBM i connections, IFS directories, IFS files and IFS filters.
  • Subsystem IFS Projects: each filter is a project directory.
  • Builds projects and single files with gmake or TOBi in the SSH terminal.
  • Edits iproj.json on a property page.
  • Environment variables per project, defaults in the preferences.
  • Runs in RDi 9.6, 9.8 and 9.9.
